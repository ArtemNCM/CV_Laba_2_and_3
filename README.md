# Виявлення будівель на супутникових знімках кампусу КПІ

Лабораторні роботи 2 і 3 з курсу «Технології Computer Vision»: знайти, обвести й порахувати
будівлі головного кампусу КПІ (Київ) на двох супутникових знімках і порівняти результат
з еталонною ручною розміткою.

> **Примітка.** Класичними алгоритмами лабораторних робіт 2 і 3 (колірні пороги, фільтрація,
> контури, морфологія тощо) мені не вдалося досягти бажаної точності: будівлі із зеленим
> дахом, темні дахи та бежеві дахи вони пропускають або плутають із тінями, дорогами
> й деревами. Тому я додав нейромережу UNet++, навчену саме на задачі виділення будівель
> на аерознімках, і дотренував (fine-tuning) її на одному з наших знімків. У результаті
> вдалося досягти прийнятного рівня детекції (див. [Результати](#результати)).
> Модель додана **як експеримент**, на додачу до основних рішень лабораторних робіт.

| Знімок | Джерело | Розмір |
|---|---|---|
| `photos/KPI_esri.jpg` | Esri Living Atlas (Landsat Explorer) | 800 × 686 |
| `photos/KPI.jpg` | Bing Maps | 665 × 565 |

Еталон `photos/KPI_esri_annotated_reference.png` містить 31 позначену будівлю. Файли
`*_roi_mask.png` обмежують пошук територією кампусу.

## Методи

| Папка | Підхід |
|---|---|
| `code/lab2` | **Лабораторна 2, растр → вектор.** Колірні пороги в HSV/Lab, межі Canny, морфологія, `findContours`, геометричні фільтри (площа, ширина, прямокутність, опуклість), `minAreaRect` / `approxPolyDP`, підрахунок. |
| `code/lab3` | **Лабораторна 3, фільтрація та покращення якості зображення.** Перед виявленням: CLAHE + медіанний фільтр. Далі: mean-shift, виявлення тіней, нарощування областей, розділення watershed, перевірка тіні з півночі, контури з прямими кутами. Тут також скрипт досліджень (R&D), що порівнює 20 комбінацій покращення і калібрує кількість будівель, і порівняння однієї будівлі на обох знімках. |
| `code/model_detection` | **Нейромережа (експеримент).** [UNet++ / EfficientNet-B4](https://huggingface.co/giswqs/whu-building-unetplusplus-efficientnet-b4), попередньо навчена на датасеті WHU Building; дотренування на KPI_esri з еталонною розміткою. |

Спільний код:
- `code/common.py`: шляхи, завантаження, папки результатів, малювання.
- `code/evaluate_reference.py`: переносить еталон на кожен знімок через гомографію (SIFT + RANSAC) і рахує precision, recall, IoU та кількість знайдених еталонних будівель.

## Встановлення

Python 3.12.

```bash
pip install -r requirements.txt
```

Для `code/model_detection` додатково:

```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r code/model_detection/requirements.txt
```

Ваги попередньо навченої моделі (84 МБ) завантажуються з Hugging Face під час першого запуску.

## Запуск

Кожен запуск обробляє обидва знімки, показує результати й зберігає все в нову пронумеровану
папку `output/runX_<назва>`: `report.txt`, позначені знімки, маски, проміжні кроки.
Параметр `--no-show` вимикає вікна з результатами.

```bash
python code/lab2/buildings_detection.py
python code/lab3/buildings_detection.py
python code/lab3/research.py                          # ~7 хв, дослідження для лабораторної 3
python code/model_detection/model_detection.py        # попередньо навчена мережа
python code/model_detection/finetune.py               # ~15 хв на CPU: навчання на KPI_esri, тест на KPI
python code/model_detection/model_detection.py --finetuned
```

## Результати

Оцінки відносно еталонної розмітки. Еталон містить 24 блоки, бо будівлі, що торкаються одна
одної, зливаються в один блок.

| Метод | KPI_esri IoU | KPI_esri знайдено | KPI (Bing) IoU | KPI (Bing) знайдено | Порахована кількість (esri / Bing) |
|---|---|---|---|---|---|
| Лабораторна 2 | 0.40 | 15/24 | 0.35 | 16/24 | 23 / 27 |
| Лабораторна 3 без покращення | 0.49 | 20/24 | 0.43 | 19/24 | 27 / 27 |
| **Лабораторна 3** (CLAHE + медіанний фільтр) | **0.52** | **21/24** | **0.52** | **22/24** | **31** / 28 |
| UNet++ попередньо навчена (+ вирівнювання гістограми, різкість) | 0.39 | 19/24 | 0.39 | 18/24 | 38 / 42 |
| UNet++ дотренована на KPI_esri | 0.78 *(навчальний знімок)* | 24/24 | **0.66** | 22/24 | 26 / 22 |

Зауваження:

- Дотреновану мережу чесно перевірено лише на KPI (Bing), бо навчалася вона на KPI_esri.
  Обидва знімки показують ті самі будівлі, тож на новій території результат, імовірно, був би нижчим.
- Дотренована мережа рахує менше будівель (22–26 замість 31): будівлі, що стоять впритул,
  зливаються в один контур.
- Параметри лабораторної 3 (зокрема мінімальна площа будівлі, за якої кількість дорівнює 31)
  підібрані за еталоном, тож її оцінки дещо оптимістичні.
- Контури еталону намальовані товстими лініями: навіть ідеальне виявлення, що проходить
  на 2 px усередині контуру, дало б IoU ≈ 0.8.
- Найскладніші будівлі для класичних методів: головний корпус із зеленим дахом (#7, #12),
  темний дах #24 (виглядає як тінь) і бежеві дахи #21, #25.
